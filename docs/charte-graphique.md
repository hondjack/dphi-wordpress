## 1. Le Logo DPhi

### 1.1 Versions officielles

Le logo DPhi existe en deux versions. Aucune modification des couleurs,
proportions ou orientation n'est autorisée.

| Version | Usage |
|---|---|
| **Glyph seul** (logo groupe) | Documents juridiques, en-têtes pages intérieures, applications mobiles (icône), tampons |
| **Logo complet** (avec texte DPhi TV) | Pages de couverture, site web, réseaux sociaux, documents produits, supports marketing |

### 1.2 Règles d'usage logo

**Zone de protection** : espace libre autour du logo égal à 1/5 de sa hauteur.

**Fond autorisé** : blanc uniquement. Ne jamais placer le logo sur un fond coloré ou une photo.

**Taille minimale** : Glyph 20px / 0,7cm. Logo complet 80px / 2,8cm.

**Couleurs** : toujours en couleur sur fond blanc. Jamais de version recolorée.

**Déformation** : redimensionner uniquement de manière proportionnelle. Aucun étirement.

## 2. Palette de Couleurs Officielle

La palette DPhi est réduite à l'essentiel. Moins de couleurs, utilisées avec
rigueur, produisent plus d'impact qu'une palette étendue mal maîtrisée.

### 2.1 Couleurs — détail complet

**#1E3F66 — Bleu acier profond**
- RGB : rgb(30, 63, 102)
- Rôle : COULEUR PRINCIPALE
- Usage : titres H1, chiffres clés, numéros de section, bordures fines,
  en-têtes de tableaux
- Règle : utilisée avec parcimonie — sur 10-15% des surfaces maximum

**#CBB06B — Gold**
- RGB : rgb(203, 176, 107)
- Rôle : COULEUR IDENTITAIRE
- Usage : uniquement pour la lettre **D** dans "DPhi" sur les titres principaux
- Règle : maximum 1-2 occurrences par page. Ne jamais utiliser comme couleur
  de fond ou de tableau.

**#222222 — Anthracite**
- RGB : rgb(34, 34, 34)
- Rôle : TEXTE PRINCIPAL
- Usage : corps de texte, titres secondaires H2 et H3, contenu des tableaux
- Règle : préféré au noir pur (#000) qui est trop dur

**#FFFFFF — Blanc**
- RGB : rgb(255, 255, 255)
- Rôle : FOND UNIVERSEL
- Usage : 90% des surfaces
- Règle : le blanc fait le design — l'espace négatif est le meilleur outil graphique

**#F4F4F4 — Gris très clair**
- RGB : rgb(244, 244, 244)
- Rôle : TABLEAUX
- Usage : alternance de lignes dans les tableaux de données
- Règle : ne jamais utiliser comme fond de slide ou de section — trop proche du blanc

**#12A29A — Teal**
- RGB : rgb(18, 162, 154)
- Rôle : RÉSERVÉ AU LOGO
- Usage : logo DPhi uniquement
- Règle : ne sort jamais du logo dans les documents. Ne pas utiliser comme
  couleur d'accent, de titre ou de fond.

## 3. Typographie

Calibri pour tous les documents. La sobriété typographique fait la différence
entre un document professionnel et un document ordinaire.

### 3.1 Hiérarchie — documents Word et emails

| Style | Spécification | Règle |
|---|---|---|
| H1 — Titre de section | Calibri Bold 16pt, #1E3F66 | Bordure gauche bleue 3pt. Indent 0,5cm. Espace avant 20pt. |
| H2 — Sous-section | Calibri Bold 12pt, #222222 | Bordure bas bleue 1pt fine. Espace avant 14pt. |
| Corps de texte | Calibri Regular 11pt, #222222 | Justifié. Interligne 1,15. Espace après 6pt. |
| Chiffre clé | Calibri Bold 18-28pt, #1E3F66 | Utilisé seul sur sa ligne. Grand, aéré, sobre. |
| Note / légende | Calibri Italic 9pt, gris moyen | Sous les tableaux et graphiques. |
| D de DPhi | Calibri Bold, même taille que le titre, #CBB06B | Uniquement la lettre D dans DPhi. Max 2 fois par page. |

### 3.2 Polices par support

| Support | Police |
|---|---|
| Documents Word (.docx) | Calibri — préinstallée Windows et macOS |
| Présentations PowerPoint | Calibri — cohérence avec les documents Word |
| Pages HTML / Web | `'Calibri', 'Segoe UI', Arial, sans-serif` |
| Documents juridiques uniquement | Times New Roman — statuts, contrats, accords |
| Code et valeurs techniques | Courier New — extraits de code, valeurs HEX |

## 4. Règles d'Application par Support

### 4.1 Documents Word

| Élément | Règle |
|---|---|
| Page de couverture | Logo glyph en haut à gauche, petit. Titre avec D gold + "Phi" bleu + reste anthracite. Ligne bleue fine sous le titre. Fond blanc. |
| Titres H1 | Bordure gauche bleue 3pt. Calibri Bold 16pt bleu. Pas de fond coloré. |
| Titres H2 | Calibri Bold 12pt anthracite. Bordure bas bleue 1pt. Pas de fond. |
| Tableaux | En-tête : fond bleu, texte blanc. Lignes alternées : blanc / #F4F4F4. Valeurs clés en bleu bold. Pas d'autres couleurs. |
| Chiffres clés | Calibri Bold 18-28pt bleu. Seuls sur leur ligne. Espace généreux autour. |
| Le D de DPhi | Gold #CBB06B uniquement. Maximum 2 fois par page. Uniquement dans "DPhi" en titre. |
| Logo intérieur | Glyph seul, aligné à droite, largeur 1,6cm, espace après 0,4cm. |

### 4.2 Présentations PowerPoint — style McKinsey/BCG

**Fond de slide** : blanc #FFFFFF sur toutes les slides de contenu.
Sombre uniquement pour couverture et slide finale.

**Titre de slide** : le titre EST la conclusion — pas le sujet.
Exemple : "87% des Tchadiens sans internet — DPhi TV est la première solution"
et non "Le problème".

**1 idée par slide** : une slide = un chiffre ou une idée.
Maximum 5 lignes de texte hors titre.

**Chiffre clé** : grand (48-60pt), bleu, seul sur sa ligne. Le reste prouve ce chiffre.

**Couleurs slides** : bleu #1E3F66 pour les accents. Anthracite pour le texte.
Blanc pour le fond. Le teal reste dans le logo en coin.

**Tableaux PPT** : même règle que Word : bleu / blanc / gris clair. Pas d'autre couleur.

**Pied de slide** : logo glyph petit à gauche. Nom document + "Confidentiel"
centré 8pt gris. Numéro de slide à droite en bleu.

### 4.4 Thème WordPress (règles spécifiques)

**theme.json** : déclarer la palette DPhi dans Gutenberg.
Désactiver les couleurs custom — le CM ne peut pas sortir de la charte.
Désactiver les dégradés — interdits par la charte.

**En-tête tableaux Gutenberg** : `background: var(--dphi-blue); color: #FFFFFF;`

**Blocs custom** :
- `dphi/hero` : fond blanc, titre H1 bleu, sous-titre anthracite, CTA bleu
- `dphi/kpi-row` : chiffres en bleu bold sur fond blanc, labels anthracite
- `dphi/cards-verticales` : cartes fond blanc, bordure fine, titre bleu
- `dphi/section-titre` : H1 avec bordure gauche 3px bleu acier

## 6. Ce qui est Interdit — Règles Absolues

Ces règles évitent qu'un document DPhi soit perçu comme généré par une IA
ou produit sans charte. Elles sont non négociables.

| Interdit | Raison |
|---|---|
| Fonds colorés sur les sections de contenu | Uniquement fond blanc. Teal, bleu ou gold en fond = signature IA. |
| Teal `#12A29A` en dehors du logo | Ne sort jamais du logo. Pas de titres teal, pas de tableaux teal, pas de fonds teal. |
| Gold `#CBB06B` comme couleur de surface | Gold = lettre D uniquement. Jamais en fond de cellule ou de bandeau. |
| Emojis comme éléments graphiques | Aucun emoji. Utiliser des chiffres et des formes géométriques. |
| Fonds sombres (`#1A2A3A` ou similaire) | L'ancien fond sombre bleu-nuit est la première signature d'un deck généré par IA. Supprimé définitivement. |
| Cellules de tableau multicolores | Uniquement bleu (en-tête) / blanc / gris clair #F4F4F4. |
| Dégradés et effets | Aucun dégradé, ombre portée, reflet ou effet. Flat design sobre uniquement. |
| Plus de 2 couleurs par page hors texte | Bleu + texte anthracite. Gold max 2 fois. Rien d'autre. |
| Texte blanc sur fond autre que bleu acier | Interdit sauf en-tête de tableau (#1E3F66) |
